# LLM and Agent Consumption

To support automated coding agents, language models, and headless integrators, this documentation platform offers plain-text endpoints stripped of visual layout elements.

## Available Endpoints

- **/llms.txt**: A brief structural outline map summarizing core documentation layouts and matching resource indexes.
- **/llms-full.txt**: An aggregated, raw markdown file containing the entire project documentation corpus separated by distinct structural page delimiters.
- **[route].md**: Every documentation route can be viewed as raw markdown text content by appending `.md` straight to the end of the standard URL path.
